# 🎨 Color Palette Generator

A simple and interactive Color Palette Generator built using HTML, CSS and JavaScript.

## 🚀 Features

- 🎨 Generate random color palettes
- 🔢 Generate HEX color codes
- 📋 Copy HEX color code
- 🔄 Generate new palette
- 📱 Responsive design
- ✨ Interactive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Clipboard API
